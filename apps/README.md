# Aplikacje i Moduły Wykonawcze (`apps/`)

Moduły uruchomieniowe platformy Antigravity Mesh:

| Aplikacja | Ścieżka | Opis |
| :--- | :--- | :--- |
| **Android Mobile App** | [`apps/android`](android/README.md) | Aplikacja Android (Jetpack Compose) do podglądu klastra, czatu AI i auto-aktualizacji |
| **Rust Native Daemon** | [`apps/daemon-rs`](daemon-rs/) | Natywny demon w tle z menu zasobnika systemowego (tray) |
| **Python Daemon** | [`apps/daemon-py`](daemon-py/) | Referencyjny serwer MCP / HTTP JSON-RPC węzła |
